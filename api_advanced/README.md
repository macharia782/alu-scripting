# API Advanced

Python scripts that query the Reddit API to retrieve subscriber counts, fetch top hot posts, and recursively paginate through subreddit articles to count keyword frequencies.

## Files
* `0-subs.py` - Returns the total number of subscribers for a given subreddit.
* `1-top_ten.py` - Prints the titles of the first 10 hot posts for a given subreddit.
* `2-recurse.py` - Recursively returns a list of all hot article titles for a given subreddit.
* `3-count.py` - Recursively counts and prints sorted keyword occurrences across all hot article titles.
